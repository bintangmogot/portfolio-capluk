## 2. Gambaran Proyek

### Apa yang Akan Dibangun

Website portfolio **satu halaman** untuk Herdanius Larobu (Capluk) — seorang motion graphic designer, VFX artist, dan sutradara film veteran Indonesia dengan pengalaman 25+ tahun di industri.

### Konsep Inti

> **Tidak ada scrolling vertikal.** Website bekerja seperti **presentasi sinematik** — pengguna bernavigasi secara horizontal antar section dengan klik tab navigasi atau gesture scroll (scroll ke bawah = geser kiri, scroll ke atas = geser kanan). Konten detail muncul dalam **modal/popup**.

### Perilaku Scroll

|---|---|
| Scroll ke Bawah (touchpad/mouse) | Konten geser ke **KIRI** (section berikutnya) |
| Scroll ke Atas (touchpad/mouse) | Konten geser ke **KANAN** (section sebelumnya) |
| Klik tab | Geser ke section tersebut dengan transisi |
| Klik item portfolio | Buka modal dengan pemutar video + detail |

### Teks Background Dinamis

**Teks besar berukuran oversized** dari nama section yang aktif muncul sebagai elemen background di belakang layer konten. Ketika user berpindah section, teks beranimasi berganti ke nama section yang baru.

```
CONTOH — User klik "Portfolio":
┌─────────────────────────────────────────────┐
│                                             │
│   P O R T F O L I O    ← Teks besar pudar   │
│        [Foto Hero di atasnya]               │
│        [Konten di atasnya]                  │
│                                             │
└─────────────────────────────────────────────┘

CONTOH — User klik "About":
┌─────────────────────────────────────────────┐
│                                             │
│      A B O U T         ← Animasi masuk       │
│        [Foto Hero di atasnya]               │
│        [Konten di atasnya]                  │
│                                             │
└─────────────────────────────────────────────┘
```

**Perilaku:**
- Teks menggunakan font **Thunder** dengan ukuran sangat besar (misalnya 15–25vw)
- Opacity rendah (~0.05–0.1) sehingga berfungsi sebagai layer background yang halus
- Saat berpindah section, teks lama animasi keluar (fade + geser sedikit) dan teks baru animasi masuk
- Teks berada **di belakang** foto hero dan layer konten (z-index stacking)
- Pada **tema grayscale**, teks background menggunakan warna putih/abu-abu muda dengan opacity sangat rendah

### Perilaku Foto Hero

Foto hero (portrait penuh Capluk) bersifat **statik** tapi **bertransisi/bergerak** ketika user mengklik tab section yang berbeda. Ini menciptakan kesan sinematik — seperti perubahan sudut kamera.

### Sistem Tema

| Tema | Deskripsi |
|------|-----------|
| **Sinematik Hangat** (Default) | Gradient oranye/merah (#ff6731 → #a11f03), nada hangat, nuansa sinematik |
| **Grayscale** (Alternatif) | Versi desaturasi, monokromatik — bukan toggle gelap/terang sederhana tapi perubahan **mood** sepenuhnya |

**Lokasi toggle:** Monogram "C" di pojok kiri atas berfungsi sebagai toggle tema dengan animasi premium.

#### Tema Grayscale (Alternatif)

| Token | Nilai | Penggunaan |
|-------|-------|------------|
| `--gradient-start` | `#4a4a4a` | Gradient desaturasi |
| `--gradient-end` | `#1a1a1a` | Arang tua |
| `--text-primary` | `#E0E0E0` | Teks utama |
| `--hero-filter` | `grayscale(100%)` | Foto hero didesaturasi |

> [!IMPORTANT]
> Tema grayscale BUKAN sekadar CSS `filter: grayscale(1)`. Harus didesain sebagai skema warna alternatif yang terasa seperti **mood berbeda** — seperti beralih dari film berwarna ke sinema hitam-putih.

> - **Thunder** → Judul section, teks hero ("Creative Director", "Motion Designer")

> - **Bebas Neue** → Tab navigasi, label kategori, heading kecil
> - **Bruno Ace** → Tagline ("Analog Roots. Digital Future."), label terkait teknologi

### Spesifikasi Glassmorphism

Klien menginginkan efek glassmorphism terasa lebih seperti **kaca asli** — dengan area yang hampir **tidak terlihat/transparan** dan bagian yang **lebih tebal/lebih buram**.

```css
/* Contoh implementasi kartu glass */
.glass-card {
  background: linear-gradient(
    135deg,
    rgba(255, 255, 255, 0.02) 0%,    /* Hampir tidak terlihat */
    rgba(255, 255, 255, 0.08) 40%,    /* Halus */
    rgba(255, 255, 255, 0.15) 100%    /* Buram lebih tebal */
  );
  backdrop-filter: blur(20px) saturate(150%);
  border: 1px solid rgba(255, 255, 255, 0.15);
  border-radius: 16px;
}
```

### Tata Letak

| Properti | Nilai |
|----------|-------|
| **Lebar Konten Maksimum** | `1440px` (di tengah, konten tetap saat zoom out) |
| **Breakpoint Responsif** | Mobile (<768px), Tablet (768–1024px), Desktop (>1024px) |
| **Foto Hero** | Full-bleed dalam container konten |
| **Navigasi** | Bar mengambang, bawah-tengah, selalu terlihat |

## 6. Teknologi yang Digunakan

| Layer | Teknologi | Versi | Alasan |
|-------|-----------|-------|--------|
| **Framework** | Next.js | 15 (App Router) | SSG/SSR untuk SEO, ekosistem React, terbaik untuk situs portfolio |
| **Bahasa** | TypeScript | Terbaru | Type safety, DX lebih baik |
| **Styling** | TailwindCSS | 4 | Prototyping cepat, utility-first |
| **Animasi** | GSAP | Terbaru | Standar industri untuk situs kreatif, performan, kontrol timeline |
| **Internasionalisasi** | next-intl atau next-i18next | Terbaru | Pergantian bahasa EN/ID |
| **Embed Video** | react-youtube atau lite-youtube-embed | Terbaru | Embed YouTube yang performan dengan lazy loading |
| **Ikon** | Lucide React atau Phosphor Icons | Terbaru | Set ikon modern dan bersih |
| **Form** | React Hook Form | Terbaru | Penanganan form yang ringan |
| **CDN Media** | Cloudinary | - | Optimisasi gambar dengan `f_auto,q_auto` |
| **Analitik** | Vercel Analytics + Google Analytics | - | Pelacakan performa + traffic |
| **Hosting** | Vercel | - | Tier gratis, SSL otomatis, edge network |
| **Domain** | Namecheap | - | Registrasi, lalu arahkan DNS ke Vercel |
| **PWA** | next-pwa | Terbaru | Service Worker untuk akses offline |

> [!NOTE]
> **Kenapa GSAP bukan Framer Motion?**
> GSAP memberikan kontrol lebih detail untuk timeline kompleks, horizontal scrolling, dan transisi sinematik — yang persis dibutuhkan proyek ini. Horizontal scroll + transisi section + pergerakan foto hero adalah use case sempurna untuk plugin ScrollTrigger dan Timeline milik GSAP.

## 7. Animasi & Interaksi

### Level Animasi: ⬛⬛⬛⬛⬜ Berat (Tanpa 3D)

| Animasi | Tipe | Library | Deskripsi |
|---------|------|---------|-----------|
| **Loading/Intro** | Sequence pembuka | GSAP Timeline | Intro sinematik saat website pertama dimuat — reveal logo, animasi teks, fade-in foto hero |
| **Transisi Section** | Slide horizontal | GSAP + ScrollTrigger | Slide kiri/kanan antar section. Dipicu oleh scroll atau klik tab |
| **Pergerakan Foto Hero** | Parallax/pergeseran | GSAP | Foto bergerak/bertransisi halus saat berpindah section — seperti perubahan sudut kamera |
| **Animate-In Teks** | Judul hero | GSAP SplitText atau custom | "Creative Director", "Motion Designer", dll. muncul dengan animasi (fade, slide, atau stagger) |
| **Highlight Tab** | State aktif | CSS + GSAP | Tab aktif memiliki state highlight dengan transisi halus |
| **Reveal Nav Bar** | Slide ke atas | GSAP | Nav awalnya hanya tab, lalu naik untuk menampilkan area konten di bawahnya |
| **Hover Portfolio** | Preview video | HTML5 Video / YouTube API | Autoplay video dengan suara saat hover |
| **Kartu Glassmorphism** | Tilt + parallax | Vanilla Tilt atau custom | Efek tilt 3D saat hover untuk kartu section Journey |
| **Toggle Tema** | Monogram "C" | GSAP Timeline | Animasi premium saat berganti tema — cross-fade, perubahan warna |
| **Kursor Custom** | Kursor kreatif | CSS + JS | Desain kursor custom (mungkin tombol play atau crosshair) |
| **"Open for Collaboration"** | Pulse | Animasi CSS | Denyut halus titik hijau |
| **Buka/Tutup Modal** | Scale + fade | GSAP | Modal muncul dengan animasi scale dan opacity |
| **Teks Background** | Label section | GSAP + SplitText | Nama section berukuran besar (misalnya "PORTFOLIO", "ABOUT") animasi masuk/keluar di belakang layer konten saat berpindah tab. Menggunakan font Thunder 15–25vw, opacity rendah (~0.05–0.1). Transisi fade + slide. |
| **Ganti Bahasa** | Morph konten | Transisi React | Pergantian teks halus antara EN/ID |

> [!WARNING]
> Animasi berat + YouTube embed + video autoplay = potensi masalah performa di perangkat low-end.
> **Mitigasi:** Lazy load semua, gunakan `IntersectionObserver`, implementasi `prefers-reduced-motion`, dan gunakan `lite-youtube-embed`.

## 12. Penilaian Risiko

| Risiko | Level | Mitigasi |
|--------|-------|----------|
| **Timeline 10 hari sangat ketat** untuk lingkup ini | 🔴 Tinggi | Prioritaskan fitur MVP, tunda studi kasus + artikel untuk pasca-launch |
| **Animasi berat bisa lag** di mobile/low-end | 🟡 Sedang | `prefers-reduced-motion`, lazy loading, kurangi kompleksitas GSAP di mobile |
| **Embed YouTube lambat** saat load awal | 🟡 Sedang | Gunakan `lite-youtube-embed`, facade pattern, lazy load iframe |
| **Konten belum siap** (foto, video, email) | 🟡 Sedang | Gunakan konten placeholder, ganti saat siap |
| **Font Thunder** bukan Google Font (download terpisah) | 🟢 Rendah | Self-host file font, subset untuk karakter yang dibutuhkan |
| **Tema grayscale** membutuhkan kerja desain ganda | 🟡 Sedang | Gunakan CSS custom properties + palet terkontrol, bukan redesign penuh |
| **Tanpa CMS** berarti setiap update konten butuh developer | 🟢 Rendah | File konten terstruktur dengan baik (JSON/MDX) membuat update mudah |
