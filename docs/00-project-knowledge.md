## 2. Project Overview

### What We're Building

A **single-page portfolio website** for Herdanius Larobu (Capluk) — a veteran Indonesian motion graphic designer, VFX artist, and film director with 25+ years in the industry.

### Core Concept

> **No vertical scrolling.** The website operates like a **cinematic slide deck** — users navigate horizontally between sections by clicking nav tabs or using scroll gestures (scroll down = slide left, scroll up = slide right). Detailed content appears in **modals/popups**.

## 3. Architecture & Interaction Model

### Navigation Behavior

```
INITIAL STATE (Website loaded):
┌─────────────────────────────────────────────┐
│                                             │
│        [Hero Photo + Role Titles]           │
│          Creative Director                  │
│          Motion Designer                    │
│          VFX Artist                         │
│          Video Production Specialist        │
│                                             │
│  ┌───────────────────────────────────┐      │
│  │  Portfolio │ Expertise │ About │  │      │
│  │  Journey   │ Connect             │      │
│  └───────────────────────────────────┘      │
│        ↑ Only tab names visible             │
│                                             │
└─────────────────────────────────────────────┘

AFTER USER CLICKS TAB or SCROLLS:
┌─────────────────────────────────────────────┐
│                                             │
│        [Hero Photo TRANSITIONS/MOVES]       │
│                                             │
│  ┌───────────────────────────────────┐      │
│  │  Portfolio │ Expertise │ About │  │      │
│  │  Journey   │ Connect             │      │
│  ├───────────────────────────────────┤      │
│  │  [SECTION CONTENT APPEARS HERE]  │      │
│  │  Nav bar slightly moves UP       │      │
│  │  Content area slides up below nav│      │
│  └───────────────────────────────────┘      │
│                                             │
└─────────────────────────────────────────────┘
```

### Scroll Behavior

| User Action | Website Response |
|---|---|
| Scroll Down (touchpad/mouse) | Content slides **LEFT** (next section) |
| Scroll Up (touchpad/mouse) | Content slides **RIGHT** (previous section) |
| Click tab | Slide to that section with transition |
| Click portfolio item | Open modal with video player + details |

### Dynamic Background Text

A **large, oversized text** of the current section name appears as a background element behind the content layer. When the user switches sections, the text animates to the new section name.

```
EXAMPLE — User clicks "Portfolio":
┌─────────────────────────────────────────────┐
│                                             │
│   P O R T F O L I O    ← Large faded text   │
│        [Hero Photo overlaid on top]         │
│        [Content overlaid on top]            │
│                                             │
└─────────────────────────────────────────────┘

EXAMPLE — User clicks "About":
┌─────────────────────────────────────────────┐
│                                             │
│      A B O U T         ← Animates in        │
│        [Hero Photo overlaid on top]         │
│        [Content overlaid on top]            │
│                                             │
└─────────────────────────────────────────────┘
```

**Behavior:**
- Text uses the **Thunder** display font at a very large size (e.g., 15–25vw)
- Opacity is low (~0.05–0.1) so it acts as a subtle background layer
- When switching sections, the old text animates out (fade + slight slide) and the new one animates in
- The text sits **behind** the hero photo and content layers (z-index stacking)
- On the **grayscale theme**, the background text should be white/light gray with very low opacity

### Hero Photo Behavior

The hero photo (full-bleed portrait of Capluk) is **static** but **transitions/moves** when the user clicks a different section tab. This creates a cinematic feel — like a camera angle change.

> - **Bruno Ace** → Tagline ("Analog Roots. Digital Future."), tech-related labels

### Glassmorphism Spec

The client wants the glassmorphism to feel more like **real glass** — with areas that are nearly **invisible/transparent** and parts that are **thicker/more frosted**.

```css
/* Example glass card implementation */
.glass-card {
  background: linear-gradient(
    135deg,
    rgba(255, 255, 255, 0.02) 0%,    /* Nearly invisible */
    rgba(255, 255, 255, 0.08) 40%,    /* Subtle */
    rgba(255, 255, 255, 0.15) 100%    /* Thicker frost */
  );
  backdrop-filter: blur(20px) saturate(150%);
  border: 1px solid rgba(255, 255, 255, 0.15);
  border-radius: 16px;
}
```

## 7. Animations & Interactions

### Animation Level: ⬛⬛⬛⬛⬜ Heavy (No 3D)

| Animation | Type | Library | Description |
|-----------|------|---------|-------------|
| **Loading/Intro** | Entry sequence | GSAP Timeline | Cinematic intro when site first loads — logo reveal, text animation, hero photo fade-in |
| **Section Transitions** | Horizontal slide | GSAP + ScrollTrigger | Slide left/right between sections. Triggered by scroll or tab click |
| **Hero Photo Movement** | Parallax/shift | GSAP | Photo subtly moves/transitions when switching sections — like a camera angle change |
| **Text Animate-In** | Hero titles | GSAP SplitText or custom | "Creative Director", "Motion Designer", etc. animate in (fade, slide, or stagger) |
| **Tab Highlight** | Active state | CSS + GSAP | Active tab has highlighted state with smooth transition |
| **Nav Bar Reveal** | Slide up | GSAP | Nav starts as just tabs, then slides up to reveal content area below |
| **Portfolio Hover** | Video preview | HTML5 Video / YouTube API | Autoplay video with sound on hover |
| **Glassmorphism Cards** | Tilt + parallax | Vanilla Tilt or custom | 3D tilt effect on hover for Journey section cards |
| **Theme Toggle** | "C" monogram | GSAP Timeline | Premium animation when switching themes — cross-fade, color morph |
| **Custom Cursor** | Creative cursor | CSS + JS | Custom cursor design (possibly a play button or crosshair) |
| **"Open for Collaboration"** | Pulse | CSS animation | Subtle green dot pulse |
| **Modal Open/Close** | Scale + fade | GSAP | Modals animate in with scale and opacity |
| **Background Text** | Section label | GSAP + SplitText | Large oversized section name (e.g., "PORTFOLIO", "ABOUT") animates in/out behind content layer when switching tabs. Uses Thunder font at 15–25vw, low opacity (~0.05–0.1). Fade + slide transition. |
| **Language Switch** | Content morph | React transition | Smooth text swap between EN/ID |

> [!WARNING]
> Heavy animations + YouTube embeds + video autoplay = potential performance issues on low-end devices.
> **Mitigation:** Lazy load everything, use `IntersectionObserver`, implement `prefers-reduced-motion` media query, and use `lite-youtube-embed` for performance.
