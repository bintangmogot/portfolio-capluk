## 9. TABLET (768px)

Tablet follows the desktop layout with these adjustments:
- Navigation tabs become slightly smaller
- Content area reduces padding
- Expertise columns stack to 2 columns (Production + Motion on top, Tools below)
- Journey cards arrange in 2x2 grid instead of 4-column
- Background text scales to ~12vw
