Level 2: The Power of Types ⚡

TypeScript gives you "Type Safety." This means you can't accidentally use a component the wrong way. It's like a contract between you and the code.

1. Unions (Choices)

Instead of just "string", you can say a variable must be one of specific words.

type Status = 'Loading' | 'Success' | 'Error';

If you try to set status to 'Pizza', TypeScript will tell you NO.

2. Optional (?) Props

Sometimes we only want to provide data if we HAVE it. The ? makes it optional.

interface MyProps { label: string; unit?: string; // Maybe yes, maybe no }
