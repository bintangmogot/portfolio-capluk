The "Secret" Syntax

const [count, setCount] = useState<number>(0);

The "number" inside the brackets tells TypeScript that this state will ONLY ever be a digit.

const [isHappy, setIsHappy] = useState<boolean>(true);

True or False. Great for toggles, menus, and modes.
