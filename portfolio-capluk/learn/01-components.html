Level 1: Components & Props

Next.js apps are built from Components. A component is like a Lego brick: a reusable piece of the interface.Props (short for properties) are how you pass data into these bricks.

The "Why" of TypeScript

In this lesson, notice the interface WelcomeCardProps above. This tells the computer: *"This component MUST receive a name (text), a role (text), and a year (number)."*

If you forget to provide one, or if you provide a "word" instead of a "number,"TypeScript will scream at you before you even run the app.

// src/app/learn/01-components/page.tsx

interface WelcomeCardProps {
  name: string;      // Must be text
  role: string;      // Must be text
  yearOfStart: number; // Must be a number
}

function WelcomeCard({ name, role, yearOfStart }: WelcomeCardProps) {
  return (
    <div>
      <h3>Hello, {name}!</h3>
      <p>You are a {role}.</p>
    </div>
  );
}
